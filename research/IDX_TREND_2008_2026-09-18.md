## Reading (written after the run; the reading rule above was fixed before it)

**By the declared rule the trend rule does NOT hold out of sample — it fails one test of five: Sharpe 0.89 against random + trail10 at
0.71 (+0.18, the bar was +0.50).** The other four pass: 609 trades, t 4.1, +13.4 %/yr, 12 of 15 years positive.

What it did do, 2005-2019 on `small`: matched JKSE's return (+13.4 %/yr both) with less than half the drawdown (−27 % vs −61 %) and
stayed out of every crash — 2008 −10 % vs −47 %, 2013 −13 % vs −20 %, 2015 −18 % vs −23 %, 2018 +1 % vs −8 %, covid −5 % vs −28 %.
That is the classic trend-following profile: index-like return, crisis protection, no free lunch on top.

Why the random test is hard to read here (scratch reference, same seed, not a trial): random + trail10 on the Yahoo file made +20.7 %/yr
in 2005-09 and +19.8 % in 2010-14 — random picks among names that survived to 2026 are, in those years, picks of the era's winners.
For 2020-26 the same file gives random +4.9 %/yr (IDX data: +6.2 %), so the survivorship inflation sits in the early years. By 5-year
block (`small`, rule vs random): 2005-09 Sharpe 1.10 vs 0.77, mDD −18 % vs −68 %; 2010-14 1.10 vs 0.90, −19 % vs −32 %; 2015-19
0.44 vs −0.08, −26 % vs −48 % (rule +5.5 %/yr, random −3.4 %). The rule's advantage is in the drawdown every block and in return only
where survivorship stops flattering random; it is not the +24 pp/yr gap of 2020-26.

Calibration: the same rule on the Yahoo file 2020-26 gives +27.2 %/yr, Sharpe 1.21, mDD −28 % (IDX data: +29.9 %, 1.34, −30 %) — the
file does not inflate the rule itself.

**What to expect: 2020-26 (+30 %/yr) is the best five-year block in 22 years. The base rate over 2005-2019 is ≈ +13 %/yr at Sharpe
0.9, drawdowns 18-27 % per block, one weak block (2015-19, +5.5 %/yr) in the IDX small-cap bear years, and a book that sidesteps
crashes. Verdict: recorded as declared — the return edge over random is not established before 2020; the drawdown profile is.**
